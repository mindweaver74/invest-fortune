# 📈🔮 오늘의 투자 운세

> 실시간 지수 흐름 + 생년월일 운세로 보는 오늘의 투자 스탠스 — 매수 타이밍부터 관심 섹터까지

**▶ 바로 사용하기: https://mindweaver74.github.io/invest-fortune**

<br>

## ✨ 소개

오늘의 코스피·나스닥 등 주요 지수 흐름과 생년월일 운세를 함께 반영해, 하루의 투자 스탠스를 카드 한 장으로 보여주는 무료 웹 도구입니다.

- **오늘의 투자 스탠스** — 대길(적극 매수) / 길(분할 매수) / 보통(관망·소량) / 주의(관망 추천) / 흉(매도·현금) 5단계 등급과 조언 한마디
- **오늘 눈여겨볼 섹터** — 12개 업종 중 오늘의 운과 시장 분위기에 맞는 4곳 안내
- **실시간 지수 현황** — 국내 지수는 실시간, 해외 지수는 전일 종가 기준으로 등락률 표시
- **양력/음력 지원**: 음력 생년월일 체크 시 자동으로 양력 변환

## 🎯 특징

- **시장 상황 개인화 반영**: 단순히 지수가 떨어졌다고 전원에게 같은 조언을 주지 않습니다. 하락장에서도 판단력·심리 지표가 받쳐주는 사람은 낙폭과대 우량주 관심 조언을, 그렇지 않은 사람은 방어적 조언을 받도록 설계했습니다.
- **매일 바뀌는 결정론적 운세**: 생년월일 + 오늘 날짜를 시드로 사용해 같은 사람은 하루 종일 같은 결과가 나오고, 자정이 지나면 새로운 운세로 갱신됩니다.
- **GitHub Actions 자동 수집**: `fetch_indices.py`가 평일 09~16시 매시간 Yahoo Finance에서 지수를 가져와 `data/indices.json`에 저장하고, 페이지는 이 파일만 읽어 CORS 문제 없이 동작합니다.
- **완전 정적 페이지**: 외부 서버 없이 GitHub Pages + GitHub Actions만으로 동작합니다.

## 🛠️ 기술

| 항목 | 내용 |
|---|---|
| 프론트엔드 | 순수 HTML / CSS / JavaScript (의존성 0) |
| 지수 수집 | GitHub Actions(`update-indices.yml`) + `fetch_indices.py` (Yahoo Finance) |
| 데이터 | `data/indices.json` (정적 파일, 평일 매시간 갱신) |
| 반응형 | 모바일 우선, 카카오톡 인앱 브라우저 지원 |

## ⚠️ 안내

본 콘텐츠는 **오락·참고 목적의 운세 콘텐츠**로, 실제 투자 권유나 종목 추천이 아닙니다. 투자 판단과 손실의 책임은 투자자 본인에게 있으며, 반드시 전문가 상담 및 본인의 판단에 따라 투자하시기 바랍니다.
